Manual do Sistema v1.0

No nosso jogo (e nos sistemas reais), tudo funciona como um restaurante inteligente gerido pelo Node.js. Veja quem é quem:

1. O Jogador e a Tela = O Frontend

O que é: É o que você vê e clica (os botões, os menus e as cores).
No jogo: É você e o cliente olhando o cardápio e fazendo as escolhas na mesa.

2. O Cérebro do Jogo = O Backend (Node.js)

O Node.js é o garçom do restaurante. Ele é Single-threaded (trabalha sozinho no salão), mas é extremamente rápido porque usa uma estratégia muito esperta:

  • Call Stack (A Bandeja): O garçom faz uma coisa de cada vez, na ordem certa, focando no que está na bandeja dele naquele momento.
  • Não-Bloqueante (Não ficar plantado): Se um pedido demora para ficar pronto (carregar arquivo ou banco de dados), ele não fica parado esperando. Delega para a cozinha e atende outras pessoas!
  • Event Loop (O Radinho / Pager): Assim que a cozinha termina a tarefa nos bastidores, o Event Loop avisa o garçom para ele ir buscar o resultado na esteira e entregar ao cliente!
3. A Cozinha e o Estoque = O Banco de Dados

O que é: O lugar onde os dados são guardados e processados (senhas, pontuações, inventário).
No jogo: É a cozinha onde a mágica pesada acontece longe dos olhos do jogador.

🖥️ CLIENTES HTTP (Mesas de LEGO)

Navegadores enviando requisições. Se o tempo do temporizador circular estourar, a conexão cai com erro HTTP 504 Gateway Timeout.

🧍 GARÇOM (Node.js Single Thread)

No Node.js há 1 thread principal. Ela anota requisições e envia para a cozinha para continuar livre.

🍳 COZINHA DE BLOCOS (Libuv Thread Pool)

Segunda camada do Node.js onde operações de banco de dados e arquivos pesados são preparadas sem travar o garçom no salão.

🔔 ESTEIRA DE CALLBACKS (Callback Queue)

Balcão onde pratos prontos aguardam a thread recolher e devolver ao cliente (`res.json()`).

🛑 CPU BLOCKING (Travar a Thread)

Tentar resolver criptografia (POST /hash) na mão sem mandar à cozinha trava a Single Thread por 3 segundos!

🎮 Como Jogar (Passo a Passo)

1
Movimente o Garçom LEGO: Use WASD, Setas, ou clique/toque no elemento 3D desejado!
2
Pegue o Pedido na Mesa: Vá à mesa piscando e pressione ESPAÇO para colocar o pedido na mão.
3
Despache Pedidos Pesados na Cozinha: Leve pedidos azuis ou rosas para a COZINHA (Libuv) e pressione ESPAÇO para entregar o preparo.
4
Busque o Callback Pronto e Entregue: Aguarde a tarefa terminar, busque o resultado e retorne à mesa correspondente.
